# 우노체스

브라우저에서 실행하는 2인용 우노체스 프로토타입입니다. 게임은 HTML, CSS, JavaScript로 작성했고 외부 라이브러리는 사용하지 않습니다.

## 실행

Node.js가 설치된 상태에서 프로젝트 폴더에서 `npm start`를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다.

시작 화면에서 오프라인 또는 온라인 플레이를 선택할 수 있습니다. 오프라인은 한 컴퓨터에서 번갈아 두며, 턴이 바뀔 때마다 보드가 회전합니다. 온라인은 한 플레이어가 방을 호스트하고 표시된 6자리 코드를 다른 플레이어에게 전달하면 됩니다. 백·흑은 호스트 순서와 관계없이 무작위로 배정되며, 각자의 진영이 보드 아래쪽에 표시됩니다.

현재 서버는 이 컴퓨터의 `127.0.0.1`에서만 실행됩니다. 온라인 방 기능은 같은 컴퓨터에서 브라우저 탭 두 개를 열어 테스트할 수 있습니다. 방 정보는 서버 메모리에 보관되므로 서버를 재시작하면 사라집니다. 다른 컴퓨터에서 접속하는 기능은 서버를 네트워크에서 접근 가능하게 실행하거나 배포한 뒤 사용할 수 있습니다.

## 테스트

아래 명령을 순서대로 실행합니다.

```text
npm run test:functional
npm run test:edge
npm run test:regression
```

`src/chess.js`에는 체스판과 이동 규칙, `src/uno.js`에는 카드 덱과 효과, `src/app.js`에는 브라우저 화면과 입력 처리가 있습니다.

카드는 숫자 70%, 특수 카드 30% 비율로 구성됩니다. 숫자 카드 그룹 안에서 1–3은 각각 16%, 4–5는 각각 12%, 6–8은 각각 6%, 0과 9는 각각 5%입니다. 특수 카드 그룹 안에서 스킵·+2·와일드 각각 16%, 리버스·와일드 리버스 각각 15%, 특수증강 와일드·+4 와일드 각각 11%입니다.
